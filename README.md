# sauron-hackathon

Netra's Sauron hackathon, started Oct 24 2026. Everything built for the hackathon lives here.

| Path | What |
|---|---|
| `COMMON.md` | Rules every agent reads first |
| `briefs/` | One brief per agent |
| `status/` | Each agent's current state (first line DONE / BLOCKED / NEEDS-WILLIAM / WORKING) |
| `plans/` | Plans. `click-to-dispatch.md` = camera view → person boxes → Send drone |
| `tools/hagent` | Spawn and steer agents in tmux session `hack` |
